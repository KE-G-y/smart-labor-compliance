- 劳动争议仲裁应根据用工所在地、合同履行地和管辖规则确定受理机构。
- 市本级西安市劳动人事争议仲裁院电话为029-87610526，地址为西安市碑林区盐店街18号。
- 高新区派出庭电话为029-88333687，地址为高新区锦业路一号都市之门A座1601室。

- 备案类型、待遇享受和结算范围应以参保地医保政策为准。

一、参保人员省内外异地就医都需要办理异地就医备案吗？
参保人员异地就医未按参保地规定办理异地备案会影响其医保待遇。目前除三明、南平外，省内异地就医都无需办理异地就医备案；跨省异地就医均需办理异地就医备案。
注：因工作、旅游等原因异地急诊抢救人员视同已备案，无需办理异地就医备案。
二、如何办理异地就医备案？
参保人员可通过参保地
医保经办机构窗口
或
国家医保服务平台APP、支付宝、微信小程序
等多种线上渠道申请办理登记备案。
以国家医保服务平台APP为例，在【在线办理】模块，点击【异地备案】，点击【异地就医备案申请】根据提示即可完成备案。
参保人可以通过国家医保服务平台APP，点击【异地备案】，点击【备案记录】，随时查询办理进度。
三、异地就医备案有效期是多长时间？
一般来说，异地长期居住的人员备案
长期有效
，临时外出就医的人员备案有效期一般
不少于6个月
（时限以各参保地具体规定为准）。
四、异地就医可以一次备案多个地市吗？
不可以，
一次只能备案一个统筹区
。需变更备案统筹区的，可注销原备案后，再次申请新增办理。
五、参保人员如何取消异地就医备案？
参保人员可到参保地医保经办机构或通过
国家医保服务平台APP
线上渠道取消异地就医备案。
以国家医保服务平台APP为例，点击首页【异地备案】，点击【备案记录】，点击【自助开通】，选择要撤销的记录，点击【取消备案】即可撤销。
六、异地就医备案后回参保地就医还能享受医保报销待遇吗？
可以。异地长期居住或是临时外出就医的参保人员办理异地就医备案后，在备案有效期内，确需回参保地就医的，无需取消现有异地备案即可在参保地进行医保就医直接结算，并且在参保地享受的医保报销待遇与备案前一样。

# FAQ027 医保家庭共济可以跨市用吗？

## 问题

医保家庭共济可以跨市用吗？

## 相似问法

跨统筹区共济

异地家庭共济

## 标准答案

陕西省职工医保个人账户家庭共济已支持省内跨统筹区使用，只要共济人和被共济人都在省内参保，规则一致。

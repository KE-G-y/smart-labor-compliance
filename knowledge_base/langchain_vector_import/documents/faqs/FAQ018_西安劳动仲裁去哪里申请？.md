# FAQ018 西安劳动仲裁去哪里申请？

## 问题

西安劳动仲裁去哪里申请？

## 相似问法

西安仲裁

劳动仲裁地址

## 标准答案

应根据争议管辖和用工所在地联系对应仲裁机构。市本级西安市劳动人事争议仲裁院电话029-87610526，地址西安市碑林区盐店街18号；区县机构见西安市人社局公开名单。

# FAQ026 企业制度和地方政策冲突怎么办？

## 问题

企业制度和地方政策冲突怎么办？

## 相似问法

企业制度低于法规

制度冲突

## 标准答案

企业制度不得低于国家法律法规和地方强制性规定。若企业制度与政策冲突，应优先按更有利于劳动者且符合法律规定的口径处理，并尽快修订内部制度。

# FAQ009 陕西产假多少天？

## 问题

陕西产假多少天？

## 相似问法

产假

陕西生育假

## 标准答案

陕西职工符合政策生育子女的，在国家规定产假基础上增加产假60天；女职工参加孕前检查的，再增加产假10天；生育三孩的，在前述基础上再增加产假15天。

# FAQ004 新员工入职后多久要办理社保？

## 问题

新员工入职后多久要办理社保？

## 相似问法

入职社保

新员工参保

## 标准答案

国家规则要求用人单位依法为职工参加社会保险。具体办理时间和经办口径以当地社保、税务系统要求为准。企业实践中应在建立劳动关系后及时办理参保，避免断缴和补缴情形。

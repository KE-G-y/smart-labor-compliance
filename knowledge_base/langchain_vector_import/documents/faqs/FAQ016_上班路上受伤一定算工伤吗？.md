# FAQ016 上班路上受伤一定算工伤吗？

## 问题

上班路上受伤一定算工伤吗？

## 相似问法

上下班途中工伤

通勤工伤

## 标准答案

不能一概而论。上下班途中事故是否构成工伤，需要结合事故性质、责任认定、路线时间合理性等因素判断，并以工伤认定结论为准。

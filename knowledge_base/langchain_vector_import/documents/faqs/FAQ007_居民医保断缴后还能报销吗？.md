# FAQ007 居民医保断缴后还能报销吗？

## 问题

居民医保断缴后还能报销吗？

## 相似问法

医保断缴

医保等待期

## 标准答案

陕西居民医保未连续参保会影响待遇享受。集中缴费期外参保按等待期规定执行，等待期内发生的就医费用不予报销；未连续参保人员还可能增加变动等待期。

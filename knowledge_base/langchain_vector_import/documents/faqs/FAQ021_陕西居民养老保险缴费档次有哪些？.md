# FAQ021 陕西居民养老保险缴费档次有哪些？

## 问题

陕西居民养老保险缴费档次有哪些？

## 相似问法

居民养老缴费

## 标准答案

陕西自2025年6月1日起，城乡居民基本养老保险个人缴费档次为每年300元、500元、800元、1000元、1500元、2000元、3000元、4000元、5000元、6000元。

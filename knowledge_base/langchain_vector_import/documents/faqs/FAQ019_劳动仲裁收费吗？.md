# FAQ019 劳动仲裁收费吗？

## 问题

劳动仲裁收费吗？

## 相似问法

仲裁费

劳动争议仲裁费用

## 标准答案

劳动争议仲裁一般不向当事人收取仲裁费。个案资料准备、律师代理等其他费用不属于仲裁机构收费，应另行判断。

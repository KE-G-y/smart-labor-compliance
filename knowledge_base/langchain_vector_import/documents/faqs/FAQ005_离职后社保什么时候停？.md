# FAQ005 离职后社保什么时候停？

## 问题

离职后社保什么时候停？

## 相似问法

离职停保

员工离职社保

## 标准答案

离职停保需按企业与员工解除或终止劳动关系的实际时间和当地社保系统申报规则办理。平台可提示 HR 按月度申报期及时处理，具体截止时间以当地社保、税务经办系统为准。

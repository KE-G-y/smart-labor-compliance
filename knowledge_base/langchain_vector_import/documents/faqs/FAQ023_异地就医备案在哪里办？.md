# FAQ023 异地就医备案在哪里办？

## 问题

异地就医备案在哪里办？

## 相似问法

异地备案

跨省就医

## 标准答案

可通过参保地医保经办窗口、国家医保服务平台APP、支付宝、微信小程序等渠道办理。国家医保服务平台APP路径为：在线办理 -> 异地备案 -> 异地就医备案申请。

# FAQ022 养老保险关系什么时候需要转移？

## 问题

养老保险关系什么时候需要转移？

## 相似问法

养老转移

跨省转移

## 标准答案

跨省或跨制度流动通常需要转移养老保险关系；企业职工省内流动就业一般不需要转移，只需办理变更登记；已领取养老金的人员通常不再转移。

# FAQ003 陕西社保缴费基数上下限是多少？

## 问题

陕西社保缴费基数上下限是多少？

## 相似问法

社保基数

缴费基数上下限

## 标准答案

陕西2025年度职工基本养老保险、失业保险、工伤保险核定个人缴费基数相关参数为93003元，上限23250元/月，下限4650元/月。回答时需标注这是2025年度口径。

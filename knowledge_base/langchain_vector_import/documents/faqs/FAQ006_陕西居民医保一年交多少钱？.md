# FAQ006 陕西居民医保一年交多少钱？

## 问题

陕西居民医保一年交多少钱？

## 相似问法

居民医保缴费

陕西医保多少钱

## 标准答案

陕西2026年度城乡居民医保个人筹资标准为每人每年400元，财政补助标准为700元。该信息为2026年度口径，后续年度需重新核验。

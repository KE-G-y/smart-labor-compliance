# FAQ030 最低工资包括加班费吗？

## 问题

最低工资包括加班费吗？

## 相似问法

最低工资组成

## 标准答案

最低工资判断需按当地最低工资规定和工资项目口径处理。实务中不应简单用包含加班费的总收入掩盖正常工作时间工资低于最低工资的风险，建议按当地人社口径核验。

# FAQ015 员工自愿放弃社保可以吗？

## 问题

员工自愿放弃社保可以吗？

## 相似问法

放弃社保

社保承诺书

## 标准答案

不建议认可员工放弃社保。参加社会保险是用人单位和职工的法定义务，企业仅凭自愿放弃声明不能免除依法参保缴费责任。

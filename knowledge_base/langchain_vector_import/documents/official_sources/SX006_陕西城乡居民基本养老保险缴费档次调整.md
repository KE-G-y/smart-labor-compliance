#### 核心规则
- 陕西城乡居民基本养老保险缴费档次自2025年6月1日起调整。
- 缴费档次包括300元、500元、800元、1000元、1500元、2000元、3000元、4000元、5000元、6000元。
- 缴费补贴随档次变化，回答时应提示年度政策可能调整。

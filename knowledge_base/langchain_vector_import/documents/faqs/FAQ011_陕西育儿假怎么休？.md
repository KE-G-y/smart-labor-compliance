# FAQ011 陕西育儿假怎么休？

## 问题

陕西育儿假怎么休？

## 相似问法

育儿假

父母育儿假

## 标准答案

符合政策生育或依法收养子女的，在子女三周岁以内，每年给予父母双方各累计10天育儿假。育儿假期间按出勤对待，享受相应工资、福利待遇。

# FAQ017 工伤认定由谁申请？

## 问题

工伤认定由谁申请？

## 相似问法

谁申请工伤

工伤申请主体

## 标准答案

用人单位、工伤职工或其近亲属、工会组织均可能依法提出工伤认定申请。企业应及时准备劳动关系、事故经过、医疗诊断等材料，并关注法定申请期限。

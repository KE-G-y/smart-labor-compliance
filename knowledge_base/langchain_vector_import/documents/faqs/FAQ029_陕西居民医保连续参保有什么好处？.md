# FAQ029 陕西居民医保连续参保有什么好处？

## 问题

陕西居民医保连续参保有什么好处？

## 相似问法

连续参保

大病保险限额

## 标准答案

陕西明确，自2025年起连续参保满4年后每连续参保1年，大病保险最高支付限额提高不低于3000元；当年未使用医保基金报销的，次年大病保险最高支付限额也提高不低于3000元。

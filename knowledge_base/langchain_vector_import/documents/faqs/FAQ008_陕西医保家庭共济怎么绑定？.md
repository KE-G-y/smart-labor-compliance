# FAQ008 陕西医保家庭共济怎么绑定？

## 问题

陕西医保家庭共济怎么绑定？

## 相似问法

家庭共济

医保共济

## 标准答案

可通过陕西医保APP/小程序首页“家庭共济绑定”办理，阅读告知书后填写授权者和使用者信息，完成电子承诺签名并提交。使用时由使用人展示本人医保码结算。

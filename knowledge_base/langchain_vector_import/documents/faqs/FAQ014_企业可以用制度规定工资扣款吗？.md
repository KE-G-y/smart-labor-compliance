# FAQ014 企业可以用制度规定工资扣款吗？

## 问题

企业可以用制度规定工资扣款吗？

## 相似问法

工资扣款

罚款制度

## 标准答案

企业制度不得违反法律法规和最低工资等强制性规定。涉及扣款、赔偿、绩效扣减时，应有合法依据、民主程序、公示告知和证据支持，并避免导致正常劳动工资低于最低工资。

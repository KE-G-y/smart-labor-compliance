# FAQ010 陕西护理假多少天？

## 问题

陕西护理假多少天？

## 相似问法

陪产假

男方护理假

## 标准答案

陕西规定男方护理假15天；夫妻异地居住的，护理假20天；女职工生育三孩的，男方在前款基础上增加护理假10天。

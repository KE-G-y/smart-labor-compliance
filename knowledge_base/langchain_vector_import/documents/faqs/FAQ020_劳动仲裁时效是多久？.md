# FAQ020 劳动仲裁时效是多久？

## 问题

劳动仲裁时效是多久？

## 相似问法

仲裁时效

劳动争议时效

## 标准答案

劳动争议申请仲裁通常适用一年的仲裁时效期间，从当事人知道或者应当知道其权利被侵害之日起计算。特殊情形需结合具体争议类型判断。

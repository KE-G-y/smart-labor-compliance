# FAQ002 试用期工资可以低于最低工资吗？

## 问题

试用期工资可以低于最低工资吗？

## 相似问法

试用期最低工资

试用期工资底线

## 标准答案

不可以。试用期工资可以按劳动合同法约定确定，但不得低于用人单位所在地最低工资标准。陕西地区还需结合实际工作地对应的一类区、二类区、三类区标准判断。

# FAQ012 劳动合同一定要签书面的吗？

## 问题

劳动合同一定要签书面的吗？

## 相似问法

劳动合同书面

没签合同

## 标准答案

建立劳动关系应当订立书面劳动合同。已建立劳动关系未同时订立书面合同的，用人单位应在法律规定期限内补签，并注意未签书面合同可能产生的法律责任。

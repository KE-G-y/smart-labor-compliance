# FAQ013 员工不签劳动合同怎么办？

## 问题

员工不签劳动合同怎么办？

## 相似问法

员工拒签合同

不签合同

## 标准答案

企业应保留书面通知、沟通记录和签署安排证据，并在法定期限内依法处理。具体是否解除、如何通知，需要结合事实和当地裁判口径谨慎判断。
